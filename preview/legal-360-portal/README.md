# Prototipo IHA LEGAL 360 — portal de clientes

**Estado:** demostración visual; no es un servicio operativo.

## Vista previa

Este directorio contiene una página HTML autónoma:

- index.html: panel de inicio, asuntos, documentos ficticios, plazos, seguimiento y mensajes simulados.
- La navegación entre secciones es local al navegador.
- El buscador y el filtro de documentos funcionan únicamente sobre las filas ficticias incluidas en el HTML.

## Seguridad

- Todos los nombres, expedientes, profesionales, mensajes y fechas son datos de ejemplo.
- No hay autenticación, servidor, base de datos, almacenamiento, carga de archivos, mensajería real ni notificaciones.
- No introduzca datos personales, documentos reales ni información confidencial.
- No copie este prototipo al dominio público ni lo use para gestionar asuntos de clientes.

## Cómo visualizarlo

La página puede abrirse desde una previsualización HTML externa de GitHub. La disponibilidad depende de ese servicio; no equivale a un despliegue de staging controlado por IHA.
