# Presentación pública IHA

La cabecera separa marca, navegación y acciones. A partir de 1250 px, la primera columna reserva 320 px para la marca y el espacio anterior al menú. La altura objetivo es 88 px. En móvil los tres grupos se despliegan dentro de un menú desplazable.

| Patrón de referencia | Aplicación IHA |
| --- | --- |
| Plataforma y soluciones | Herramientas jurídicas, perfiles y pruebas |
| Catálogo por familia | Anfitriones, visitantes, residentes y conflictos con plataformas |
| Ficha de producto | Alcance publicado, inclusiones, exclusiones, plazo y solicitud |
| Comparación | Orientación gratuita, servicio puntual, LEGAL 360 y profesionales |
| Estado de producto | Herramientas públicas y proyecto Digital Justice OS |

El catálogo emplea un ancho máximo de 1180 px, tarjetas de 18 px de radio y separaciones fluidas. Los recursos gráficos son propios de IHA. Las fichas individuales conservan las condiciones comerciales. Al cambiar una tarifa o alcance, actualizar en el mismo cambio la ficha, el catálogo y los precios por idioma.

El flujo Premium ejecuta Playwright sobre un servidor estático. La prueba de catálogo recorre cuatro lenguas a 390, 820, 1100, 1440 y 1500 px. Las capturas se adjuntan al flujo de GitHub Actions.
