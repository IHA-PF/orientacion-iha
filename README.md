# Orientación legal IHA

Plataforma de orientación legal gratuita para consumidores, anfitriones y conflictos con plataformas digitales en Colombia.

Editada por IHA SOLUCIONES LEGALES Y TECNICAS S.A.S. · NIT 900.365.039-8 · Medellín, Colombia.

- `index.html`: la herramienta de orientación (4 idiomas, modo claro y oscuro, líneas de emergencia 123, 155, 165, 141).
- `es/`, `en/`, `fr/`, `pt/`: las fichas de derechos en páginas indexables, la guía de pruebas, las preguntas frecuentes y el plan para anfitriones, con un índice por idioma.
- `sitemap.xml`: para enviar a Google Search Console.
- `fonts/`: tipografías alojadas con el sitio (SIL Open Font License).
- `count.js`: script del contador de visitas GoatCounter (licencia ISC), alojado con el sitio.

Publicada con GitHub Pages: https://iha-pf.github.io/orientacion-iha/

## Datos y seguridad

- La página no usa cookies y no guarda las respuestas de los visitantes: la ficha se arma en el navegador y solo sale si la persona la envía por WhatsApp o correo.
- Las visitas se cuentan de forma anónima con GoatCounter (sin cookies, sin guardar la dirección IP).
- Cada página declara una política de seguridad del contenido: solo se ejecutan los scripts del propio sitio y solo se contacta al contador de visitas.
